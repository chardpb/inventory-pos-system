# Multi-Branch Inventory & Point of Sale (POS) System

A responsive, web-based inventory management and Point of Sale (POS) application engineered for multi-branch LPG distribution operations.

## Key Features
- **Multi-Branch Operations**: Tracks stock and sales across multiple business locations.
- **Role-Based Access Control (RBAC)**: Enforces permission boundaries between Admin, Manager, and Employee tiers.
- **Audit Logging & Security**: Automated session management and activity tracking.
- **Sales & Reporting**: Data analytics visualization and report exporting.

## Tech Stack
- **Backend:** PHP, MySQL (XAMPP)
- **Frontend:** HTML5, CSS3, JavaScript
- **Utilities:** PHPMailer
